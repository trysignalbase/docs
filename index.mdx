## Welcome to Signalbase

Signalbase detects what just changed at a company: a funding round, an acquisition, a new executive, a new job posting, or a custom signal you define, such as a new office or a first hire in a new market. Each event arrives within minutes with its original source and company context. Recruitment agencies use it to find the companies about to hire before the role is posted, and the same data powers your own tools, workflows and AI agents.

## Getting Started

Get your API key from the Signalbase dashboard at [trysignalbase.com/workspace/api](https://www.trysignalbase.com/workspace/api)

### Authentication

All API endpoints require a Bearer token in the `Authorization` header:

```bash
curl -X GET "https://www.trysignalbase.com/api/v2/signals/funding?page=1&limit=20" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

### Base URL

All V2 API endpoints use the following base URL:

```
https://www.trysignalbase.com/api/v2
```

### Use it from Claude or another AI agent

Signalbase also runs as an MCP server, so Claude, Cursor and other MCP clients can query signals with your API key. See [Signalbase MCP](https://www.trysignalbase.com/mcp) for the setup.

## Key Features

- **Real-time Data**: Signals detected within minutes from news, press releases, LinkedIn and job boards, each with its source
- **Advanced Filtering**: Filter by countries, categories, subcategories, date ranges, numeric ranges, and more
- **Date Presets**: Use relative date shortcuts like `last_30d`, `this_quarter`, or `last_year`
- **Flexible Sorting**: Sort results by date, amount, employee count, and other fields
- **Pagination Support**: Efficiently retrieve large datasets (up to 100 results per page)
- **Credit-based Usage**: Transparent credit consumption per API call
- **99% Uptime**: Enterprise-grade reliability
